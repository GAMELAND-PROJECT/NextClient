# Persian installer language

`Farsi.isl` is the community Persian translation distributed in the Inno Setup
source repository, retrieved on 2026-09-08:

https://github.com/jrsoftware/issrc/blob/main/Files/Languages/Unofficial/Farsi.isl

Translator attribution is retained in the file. This copy is bundled so local
and GitHub Actions builds do not depend on a compiler-installed translation.
The installer script and translation are UTF-8 with BOM.

The launcher uses Unicode Windows controls and Tahoma. GameUI language files
are intentionally unchanged. Technical module names in error details remain
in English for troubleshooting.
