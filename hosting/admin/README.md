# Allclient control panel

پنل سبک PHP برای مدیریت مستقیم فایل‌های زیر روی `gameland.cam`:

- `pinned_servers.txt`
- `client_tags.txt`
- `server_password.txt`

## نیازمندی

- PHP 8.1 یا جدیدتر
- HTTPS فعال
- Apache/cPanel با امکان اجرای PHP

## نصب در cPanel

1. در `File Manager` وارد `public_html` شوید.
2. پوشه‌ای با نام `admin` بسازید.
3. تمام فایل‌های این پوشه را داخل `public_html/admin` آپلود کنید.
4. **پیش از اولین بازکردن پنل**، از بخش `Directory Privacy` سی‌پنل برای پوشه
   `public_html/admin` یک لایه رمز موقت فعال کنید. این مرحله مانع می‌شود فرد دیگری
   قبل از شما راه‌اندازی اولیه را تصاحب کند.
5. پنل را باز کنید:

   ```text
   https://gameland.cam/admin/
   ```

6. در صفحه راه‌اندازی، رمز مدیریت را وارد و تکرار کنید. پنل خودش `config.php`
   را با Hash امن می‌سازد و صفحه راه‌اندازی برای همیشه بسته می‌شود.
7. پس از ورود می‌توانید رمز را از بخش «رمز مدیریت پنل» تغییر دهید؛ تغییر رمز
   فقط با واردکردن رمز فعلی انجام می‌شود.

## نصب روی گوشی (PWA)

پنل روی HTTPS به‌عنوان Web App قابل نصب است. اطلاعات مدیریتی، نشست‌ها و فایل‌های
داده هرگز در Cache آفلاین ذخیره نمی‌شوند؛ فقط CSS، JavaScript و آیکن Cache می‌شوند.

- Android/Chrome: پنل را باز کنید و دکمه «نصب روی گوشی» را بزنید.
- iPhone/Safari: دکمه Share و سپس `Add to Home Screen` را انتخاب کنید.
- پس از نصب، پنل مانند یک برنامه مستقل و بدون نوار مرورگر باز می‌شود.

اگر قبلاً با روش دستی `config.php` ساخته شده است، پنل مستقیماً صفحه ورود را نشان
می‌دهد و اطلاعات موجود را تغییر نمی‌دهد.

## رفتار ذخیره‌سازی

- ورودی‌ها قبل از ذخیره با قواعد خود کلاینت اعتبارسنجی می‌شوند.
- فایل ابتدا به‌صورت موقت نوشته و سپس اتمیک جایگزین می‌شود.
- قبل از هر تغییر Backup خصوصی در `admin/backups` ساخته می‌شود.
- حداکثر ۳۰ Backup اخیر هر فایل نگهداری می‌شود.
- رمز فعلی سرورها هیچ‌وقت در رابط وب نمایش داده نمی‌شود.

## نکات امنیتی

- پوشه `admin` و فایل `config.php` را داخل GitHub یا ZIP عمومی قرار ندهید.
- رمز cPanel را به‌عنوان رمز پنل استفاده نکنید.
- پنل سطح دسترسی `config.php` را هنگام راه‌اندازی روی `0600` قرار می‌دهد.
- اگر هاست Apache 2.2 قدیمی دارد، حتماً Directory Privacy را فعال کنید؛ قواعد
  `.htaccess` این پروژه برای Apache 2.4 نوشته شده‌اند.
